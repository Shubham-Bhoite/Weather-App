<h1 align="center">🌦️ Weather App</h1>


## 📌 Project Description :

The **Weather App** is a web-based application that provides real-time weather information for any city around the world. It uses the **OpenWeather API** to fetch weather data such as temperature, humidity, wind speed, and more. The app is built using a combination of **HTML**, **CSS**, and **JavaScript** on the frontend, and **Java** , **Servlets** and **JSP** on the backend.

## 🚀 Technologies Used :

- HTML
- CSS
- JavaScript
- Java
- Servlet
- JSP
- OpenWeather API
